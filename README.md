# trex_proc

## Installation

```bash
cargo build --release
```

## Usage

```bash
cargo run --release <path_to_input_csv>
```

The binary reads a CSV file with the following columns:
- `type`: Transaction type (deposit, withdrawal, dispute, resolve, chargeback)
- `client`: Client ID (u16)
- `tx`: Transaction ID (u32)
- `amount`: Transaction amount (decimal)

Output is written to stdout in CSV format with columns:
- `client`: Client ID
- `available`: Available funds (rounded to 4 decimal places)
- `held`: Held funds (rounded to 4 decimal places)
- `total`: Total funds (rounded to 4 decimal places)
- `locked`: Account lock status (true/false)

### Example

```bash
cargo run --release transactions.csv > clients.csv
```
